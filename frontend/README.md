# Frontend — Battleship UI

React 19 + Vite 8 + TypeScript UI for the slow-ahead Battleship backend.

Requires the backend running on http://localhost:8080; Vite proxies `/api` to it.

## Commands

```powershell
npm.cmd install   # install dependencies
npm.cmd run dev   # start dev server (http://localhost:5173)
npm.cmd run lint  # ESLint
npm.cmd run test  # Vitest
npm.cmd run build # type-check + production build
